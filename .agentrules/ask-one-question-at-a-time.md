# Ask one question at a time

When a design decision belongs to the owner:

1. Look in the codebase and docs first; do not ask what you can find out yourself.
2. Ask a single question, wait for the answer, then ask the next one that depends on it.
3. Offer 2-4 concrete, mutually exclusive options from the owner's point of view, and mark the one
   you recommend with a short reason.
4. Write the agreed decisions down (a decisions note or the task file) so the next agent starts
   with zero ambiguity.
